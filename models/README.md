# Models — Digital Arrest Detector

This directory contains all model artifacts used by the app. Some files are
large binary assets; they are committed via Git LFS or must be downloaded
separately as noted below.

---

## Text Scam Detection

| File | Description |
|---|---|
| `text_model.pkl` | Trained Logistic Regression classifier (TF-IDF features, balanced classes) |
| `tfidf_vectorizer.pkl` | Fitted `TfidfVectorizer` (unigrams + bigrams, English stop-words) |
| `metadata.json` | Training run metadata — accuracy, date, hyperparameters |

These are generated by `train_text.py` from `data/sms_spam.csv`.  
To retrain from scratch:

```bash
python train_text.py
```

> **Note:** `metadata.json`, `sms_spam_llm.jsonl`, `train.jsonl`, and
> `test.jsonl` are generated artefacts produced by `train_text.py` and are
> excluded from Git via `.gitignore`.

## Deepfake Video Detection

| File | Size | Description |
|---|---|---|
| `Deepfakes_detection_model.keras` | ~154 MB | Binary Keras model (EfficientNet/CNN-based binary classifier) |

**Input contract:**
- Frames resized to **224 × 224** pixels, normalized to `[0, 1]`.
- Model outputs a single sigmoid probability:
  - `> 0.5` → likely deepfake
  - `≤ 0.5` → likely real

**Provenance:**
This model was trained on a balanced dataset of real and deepfake face video
frames. If you replace it, ensure the new model accepts the same `(1, 224, 224, 3)`
input shape and produces a scalar sigmoid output.

**Limitations:**
- Sampled-frame analysis (12 frames by default) — may miss isolated deepfake
  artifacts in long videos.
- Not validated against all compression codecs; best results on uncompressed or
  lightly compressed MP4 / AVI.

> **⚠️ Placeholder / Large File Warning:** If the file you have is very small
> (< 1 MB), it is likely a placeholder stub. Download the real model weights
> from the project maintainer or your training pipeline before running the app.

## Speech-to-Text (Vosk)

Three small Vosk language models are bundled for offline transcription:

| Directory | Language | Download |
|---|---|---|
| `vosk-model-small-en-in/` | Indian English | [alphacep/vosk-model-small-en-in](https://alphacephei.com/vosk/models) |
| `vosk-model-small-hi/` | Hindi | [alphacep/vosk-model-small-hi](https://alphacephei.com/vosk/models) |
| `vosk-model-small-gu/` | Gujarati | [alphacep/vosk-model-small-gu](https://alphacephei.com/vosk/models) |

If any of these directories are missing, download and unzip the corresponding
model from <https://alphacephei.com/vosk/models> into this `models/` directory,
preserving the original folder name.

## Optional — LLM Reasoning (Ollama + Phi3:mini)

The app optionally uses a locally running Ollama server for LLM-based
verification and transcription refinement.  No model files are stored here for
this; the model is pulled separately:

```bash
# Install Ollama: https://ollama.com
ollama pull phi3:mini
ollama serve          # keep running in a separate terminal
```

The app detects Ollama availability at runtime and falls back to
heuristic/ML-only results if the server is not reachable.
